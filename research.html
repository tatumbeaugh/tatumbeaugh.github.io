Exploring FIA Data: Modeling Library

Overview:
Collaborated with the USDA Forest Service on utilizing geospatial data from Google Earth Engine combined with FIA data to predict ecological factors in under-reported regions.

This was a machine learning project focused on using the U.S. Forest Service Forest Inventory and Analysis (FIA) database to improve the ability to estimate forest characteristics at the local level. The project was divided into two teams: one focused on predicting forest mortality, while my team developed a machine learning modeling library that could estimate FIA variables across the Continental United States. We developed an interactive Streamlit and Leaflet application that combines FIA data with satellite data from Google Earth Engine, allowing users to select a local area, configure a modeling process, and generate predictions for forest characteristics such as biomass and growth.

As a member of the modeling library team, my primary contribution was cleaning, organizing, and analyzing the FIA database. I worked with the tree- and plot-level data to identify relevant variables, address inconsistencies, and prepare the data for use in machine learning models. I also analyzed the dataset to better understand forest and non-forest classifications and helped ensure that the data used by our models was accurate and reliable. This work provided the foundation for the modeling and helped our team develop a tool capable of generating localized forest estimates from large-scale environmental data.

Skills used: Geospatial data analysis, Google Earth Engine API, ML in ecology, Data visualization

Tools used: Streamlit, Leaflet, Google Earth Engine, Python, Git, Github

Collaborators: Purdue University Data Mine Program, USDA Forest Service

BRIDGING THE BLACK BOX: Explainable Anomaly Detection for Critical Infrastructure

Overview:
Cyberattacks have become more frequent and complex, increasing the chance of malicious actors targeting infrastructure. Deep learning models have shown promise in being effective at detecting anomalies, but are generally uninterpretable. Our CIS framework seeks to incorporate Explainable AI (XAI) and knowledge graphs to make a more interpretable model that enhances the provided context of each detected anomaly, while balancing the predictive accuracy of deep learning models with the added XAI.

I began this project with data exploration and preprocessing. Since I had no prior experience with network or cybersecurity data, I conducted research to understand how the data was structured and behaved. During cleaning, I identified and fixed issues such as a misspelled feature and duplicate rows. I then developed multiple XGBoost models to benchmark against our graph neural network (GNN), including both regression and classification approaches. One model used only attack data, while another used a balanced attack vs. non-attack dataset that I synthesized. I tuned these models to achieve strong performance. I also built a framework for model explainability using SHAP. After learning how SHAP values work, I applied them to interpret model predictions and understand feature importance. This became my favorite part of the project, as it deepened my understanding of how models arrive at their predictions and how explainability is quantified! This project introduced me to cybersecurity and model interpretability while strengthening my ability to collaborate in a small team.

Skills used: Data Cleaning, Data Analysis, Knowledge graphs, Cybersecurity fundamentals, Explainable AI (XAI)

Tools used: Python, Neo4j, XGBoost, SHAP, Sklearn, Pandas, Numpy, Git, Github

Collaborators: Angelo State University, AI-COE

Rhetorical Polarization on C-SPAN

Overview:
Applied natural language processing and machine learning to understand political discourse patterns and congressional voting behavior.

This research project investigated rhetorical polarization in the United States Congress by analyzing floor speeches from the 2009 U.S. Congress. Our team used more than 8,500 C-SPAN speeches to examine whether topics such as healthcare and the economy were associated with differences in political sentiment. We took a multimodal approach, using text, audio, and video data to develop machine learning models for classifying speeches as positive, negative, or neutral.

My primary contribution focused on data processing and preparation. I worked with the video and speech data to extract and prepare transcripts for analysis, testing different transcription methods to determine which approaches produced the most useful text for our models. I cleaned and organized the resulting data and helped prepare the transcripts for the team's natural language processing and machine learning workflows. This work gave me hands-on experience working with large, unstructured datasets and preparing real-world multimedia data for machine learning applications.

What I Learned: Data Science, Natural Language Processing (NLP), Text/sentiment analysis, Data visualization

Collaborators: Purdue University Data Mine Program, C-SPAN Center for Scholarship and Engagement (CCSE)
